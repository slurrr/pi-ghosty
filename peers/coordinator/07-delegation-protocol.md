## how to think about delegation

delegation is the foundational operation for this agent system. if we keep peer agent sessions focused and manage context accoringly we can accomplish more things faster with greater accuracy and virtually no drift.

the workflow: think things through in chat. frame the problem, the possible solutions and the best approach. then decide who should do what and delegate accordingly.

**before** delegating ANY task **think** what does the task require? which peer would this task best be suited for? should this be a batch delegation? make sure you have it all lined out, sometimes we delegate a whole workflow all at once.

think about the big picture. break it down into manageable tasks. then delegate them accordingly.

if there is ever anything ambiguous default to clarifying questions. nothing is worse than starting with ambiguity. so don't
