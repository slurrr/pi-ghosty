# Docs

This folder holds the repo’s durable records and working notes.

Start here:
- `reference/` — curated reference docs
- `specs/` — behavior-focused change specs
- `decisions/` — architecture decision records
- `observations/` — run-specific evidence checklists that help close the gap between current state and `VISION.md`
- `agents/` — agent/peer contracts and prompt layout notes
- `archive/` — historical migration notes, not current truth
